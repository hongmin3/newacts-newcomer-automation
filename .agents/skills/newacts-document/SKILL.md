# NEWACTS 문서

`newacts-newcomer-automation` 프로젝트 전용 스킬이다. 이 저장소 안의 NEWACTS 문서 요청에만 적용한다. 다른 프로젝트에서는 자동 적용하거나 전역 스킬로 설치하지 않는다. 사용자가 지정한 다른 형식도 임의로 바꾸지 않는다.

## 먼저 구성안을 보여 주고 멈춘다

새 문서 요청을 받으면 HTML 작성부터 시작하지 않는다.

1. 요청과 제공 자료를 읽고, 제목·문서 목적·절 순서·각 절의 핵심 내용·필요한 표나 자료를 짧은 구성안으로 정리한다. 요청에서 확인한 정보만 사용한다.
2. 구성안은 사용자가 읽는 터미널 또는 대화창에 일반 텍스트로 직접 출력한다. HTML 파일이나 브라우저 시안으로 대신 보여 주지 않는다.
3. 구성안 끝에 “이 구성으로 만들까요?”라고 묻고 사용자 답변을 기다린다. 이 단계에서는 HTML 파일 생성·복사·편집·미리보기 실행을 하지 않는다. 기존 양식과 자료를 읽는 것은 가능하다.
4. 해당 구성안에 대해 사용자가 “오케이”, “좋아”, “그대로 만들어” 등으로 승인하면 다음 단계로 간다. 구성 수정 요청만 왔다면 수정한 구성안을 다시 보여 주고 기다린다. 침묵, 시간 경과, 과거 다른 문서 승인은 이번 승인이 아니다.

이미 구성안을 승인한 문서의 문구·수치·서식 수정은 요청 범위에서 바로 반영한다. 문서의 목적이나 구성을 크게 바꾸려는 요청이면 바뀔 구성부터 제안한다. 스킬 자체나 작성 지침의 변경 요청에는 문서 승인 절차를 억지로 적용하지 않는다.

## 승인 후 HTML 작성

- 프로젝트의 `AGENTS.md` 기본 HTML 문서 규칙과 기본 양식·사용 안내를 읽는다. 설치 경로가 링크라면 실제 스킬 디렉터리를 먼저 확인한다. 이 스킬의 프로젝트 원본은 `.agents/skills/newacts-document/`이고, 그 위치의 세 단계 위가 프로젝트 루트다.
- `docs/templates/newacts-document.html`을 복사해 승인된 구성과 내용을 넣는다. 기본 양식 자체는 사용자가 그 수정을 요청하지 않으면 보존한다.
- 원본 심벌·NEWACTS 영문 이미지, 파란 포인트와 기본 한글 글꼴을 유지한다. 정확한 시각 기준은 기본 HTML에서 가져오고 새 디자인을 임의로 만들지 않는다.
- [휴대폰 화면 기준](references/mobile.md)을 읽고 적용한다. 승인된 내용에 필요한 구역만 사용하고 예시·빈칸·불필요한 표를 남기지 않는다.
- 기본 결과물은 HTML이다. 인쇄·PDF 버튼이나 출력 전용 서식을 추가하지 않는다. PDF 변환은 사용자가 별도로 요청한 때 처리한다.
- 저장 위치와 개인정보 보존 규칙은 프로젝트 `AGENTS.md`를 따른다. 문서 작성 승인만으로 메일 전송·외부 게시·운영 시트 변경까지 승인받은 것으로 해석하지 않는다.

## 완료 전 확인

사용자가 실제로 승인한 구성안과 결과의 절 순서·핵심 내용을 대조한다. 모바일 화면 기준으로 본문·로고·표를 확인하고 결과 파일을 안내한다. 확인하지 못한 항목은 확인했다고 보고하지 않는다.

## 참조 파일

- 프로젝트 `AGENTS.md`: 작업 시작 시 읽는 저장 위치·로고·색·문서 운영 규칙.
- 프로젝트 `docs/templates/newacts-document.html`: 승인 후 복사할 기본 HTML 원본.
- 프로젝트 `docs/templates/README.md`: 양식 사용법. 승인 후 파일 작성 전에 읽는다.
- [references/mobile.md](references/mobile.md): 승인 후 HTML을 만들거나 화면을 검토할 때 읽는 모바일 기준.
