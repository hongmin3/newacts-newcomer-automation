# 휴대폰에서 읽기 편한 HTML

승인된 NEWACTS 기본 HTML의 분위기를 유지하며 작은 화면의 읽기 흐름을 우선한다.

- `viewport`를 유지하고 페이지 폭은 화면에 맞춘다. 휴대폰에서 PC 지면을 축소한 것처럼 보이게 만들지 않는다.
- 본문은 15~16px, 줄 간격은 약 1.7~1.8을 기준으로 읽기 편하게 조정한다. 제목은 짧게 쓰며 과한 굵기·좁은 자간·장식은 피한다.
- 좁은 화면의 좌우 여백은 기본 양식처럼 20~24px 정도로 둔다. 긴 문장은 문단으로 나누되 단어마다 강제로 줄바꿈하지 않는다.
- NEWACTS 원본 영문 이미지와 심벌의 비율을 유지한다. 로고와 머리말이 겹치거나 화면 밖으로 밀리지 않아야 한다.
- 파랑은 로고·소제목·표 경계의 포인트로 사용한다. 본문은 어두운 글씨와 흰 바탕으로 읽히게 한다.
- 짧은 목록은 본문이나 목록으로 쓴다. 표가 꼭 필요하면 의미를 유지하며 열을 줄이거나 둘로 나눈다. 넓은 표를 유지해야 하면 표 영역에서만 가로로 움직이게 하고 페이지 전체가 옆으로 넘치지 않게 한다. 글씨를 지나치게 줄여 맞추지 않는다.
- 360px 또는 390px 휴대폰 폭에서 제목·본문·표의 줄바꿈, 로고 로딩, 페이지 전체 가로 넘침을 확인한다. PC 폭에서도 내용이 빠지지 않는지 확인한다.
