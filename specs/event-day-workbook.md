# 행축 당일 방문·등록 시트

## 1. 목적

행사 담당자가 2026년 11월 1일에 방문자와 등록자를 적으면 전체 명단과 군별 명단에 함께 표시된다. 2025년 하반기 등록·방문 양식과 2026년 상반기 군 구분을 참고하며 과거 개인정보는 가져오지 않는다.

## 2. 범위

새 스프레드시트에 연결된 별도 Apps Script로 제공한다. 기존 등록·교육·메일 자동화의 설정과 실행 시점은 바꾸지 않는다.

## 5. 요구사항

| 카테고리 | 이름 |
|---|---|
| EVENTDAYWORKBOOK | 행축 당일 방문·등록 양방향 입력 |

### REQ-EVENTDAYWORKBOOK-001 행사 당일 빈 명단과 군별 구성

- 날짜는 `2026-11-01`, 시간대는 `Asia/Seoul`이다.
- 전체 방문·전체 등록·신군·조군·명군·총군·영군·석군·전군·임군·슬군·기타 탭을 제공한다.
- 입력 탭의 머리글은 1행에 두고 고정한다. 입력은 2행부터다.
- 행사 현황과 사용 안내 탭을 제공한다. 과거 방문자·등록자·숨겨진 옛 명단은 남기지 않는다.
- 군이 비어 있으면 기타로 기록한다. 군별 탭의 새 입력은 그 군을 기본값으로 쓴다.

### REQ-EVENTDAYWORKBOOK-002 전체와 군별 명단의 양방향 입력

1. 담당자는 전체 방문·전체 등록 또는 군별 탭에서 이름을 입력한다.
2. 관리번호를 자동으로 부여하고, 같은 기록을 해당하는 전체·군별 탭에 반영한다.
3. 어느 탭에서든 입력 항목을 수정하면 같은 관리번호의 기록이 함께 바뀐다. 군을 바꾸면 새 군으로 이동한다.
4. 여러 행 붙여넣기를 지원한다. 관리번호·수정시각·내부 비교값은 담당자가 바꾸지 않는다.

- 이름과 정리한 휴대전화가 모두 같은 경우만 기존 사람에게 연결할 수 있다. 전화번호가 없으면 이름만으로 합치지 않는다.
- 같은 번호의 다른 이름, 연락처 누락, 동명이인은 확인할 수 있도록 표시한다.
- 이름·날짜·군·체크 값·나이·생년월일·전화번호를 검사한다. 맞지 않으면 기존 기록을 보존하고 입력 행에 이유를 표시한다.

### REQ-EVENTDAYWORKBOOK-003 방문 이력과 등록 연결 및 집계

- 등록 체크를 하면 방문 체크도 유지한다. 전체 등록에서 처음 입력해도 방문자로 함께 표시한다.
- 방문 명단에는 방문 체크가 있는 사람을, 등록 명단에는 등록 체크가 있는 사람을 표시한다. 군별 탭은 해당 군의 모든 유효 기록을 보여 준다.
- 행사 현황은 관리번호를 기준으로 군별 방문·등록 인원과 합계를 계산한다. 두 명단에 표시되는 사람을 두 사람으로 세지 않는다.
- 등록을 해제해도 방문 이력은 남는다. 한 행사일의 재방문은 별도 인원을 만들지 않는다.

### REQ-EVENTDAYWORKBOOK-004 수정 충돌과 취소 복구

- 같은 항목의 동시 수정이 서로 다르면 기존 저장값을 보존하고 충돌을 기록한다. 담당자가 입력값 적용 또는 저장값 복원을 선택한다.
- 아직 처리하지 않은 다른 담당자의 입력값을 화면 갱신으로 덮어쓰지 않는다. 서로 다른 항목의 변경은 합칠 수 있다.
- 원본 저장 뒤 화면 반영이 중단되어도 다시 맞추기 메뉴로 복구한다. 오류와 잠금 대기는 화면에 표시한다.
- 행 삭제를 기록 취소로 해석하지 않는다. 취소 메뉴는 원본과 변경 이력을 보관하며 마지막 취소를 복구할 수 있다.
- 취소하거나 동일인으로 연결한 옛 기록에 대기 입력이 있으면 변경 기록에 보관한 뒤 화면에서 제외한다. 동일인 연결로 폐기한 관리번호는 취소 복구로 되살리지 않는다.
- 변경 전후 값은 이 파일의 숨겨진 기록 탭에만 남긴다. 개인정보를 저장소에 추가하지 않는다.

## 11. 테스트 사양

### TEST-EVENTDAYWORKBOOK-001 양방향 입력과 안전 경계

`tests/event-day-workbook.test.js`를 `node`로 실행하여 실제 `onEdit` 진입점에 가짜 Sheets 경계를 연결한다. 전체→군, 군→전체, 등록→방문 유지, 군 이동, 여러 행 입력, 동일인 연결, 이름만 같은 사람 분리, 입력 검사, 서로 다른 항목 수정, 동일 항목 충돌, 미처리 입력 보존, 오류 후 복구, 취소·복구를 확인한다.

실제 Google Sheets에서는 가상 인물로 양방향 입력·수정·등록 연결·군 이동·집계를 확인한 뒤 시험 자료를 제거한다. 로컬 검사는 권한과 Google의 편집 이벤트 전달을 대신 검증하지 않는다.
