# 11월 1일 행축 명단

전체 방문·전체 등록과 군별 명단을 연결한다. 등록 명단에 적으면 방문 명단에도 자동으로 추가된다.

- 순번은 각 명단에서 이름이 있는 행의 화면 순서대로 자동으로 매긴다. 번호를 직접 바꾸거나 이름을 지우면 다시 정리한다.
- 방문 명단의 `순`은 `-`로 표시한다. 등록 명단의 `순`은 입력한 값을 유지한다.
- 전체 명단은 1행 머리글 아래 2행부터 입력한다.
- 군별 탭은 원본처럼 파란 제목·빨간 열 제목·테두리 표를 쓴다. 위쪽이 방문, 아래쪽이 등록이다.
- 처음에는 방문 3~22행, 등록 27~36행에 입력한다. 자동 반영할 칸이 부족하거나 마지막 칸 바로 다음 행에 직접 적으면 5행을 더하고 등록 구역을 함께 옮긴다.
- 전체 명단에서 군을 비우면 기타가 된다. 군별 명단에서는 그 군이 기본값이다.
- 각 명단의 1행 옆에는 방문자 수·등록자 수만 표시한다.
- 등록 명단에서 이름을 비우면 등록만 해제하고 방문 이력은 남긴다.

빠르게 입력해 앞선 수정이 대기하면 다음 편집에서 같은 명단의 대기 항목을 함께 반영한다. 다른 처리가 끝나기를 최대 15초 기다린 뒤에도 차례가 오지 않으면 입력값을 남기고 안내한다.

같은 사람은 이름과 정리한 전화번호로 확인한다. 이름만 같거나 전화번호가 없으면 임의로 합치지 않는다. 같은 칸의 수정이 겹치면 셀 메모에 저장값과 입력값을 안내한다. 내용을 확인하고 그 칸에 다시 입력하면 된다.

체크박스, 등록 비율, 결신 열, 표 버튼, 추가 메뉴와 별도 현황판은 없다. 연결 정보와 변경 기록은 숨겨 둔다. 숨겨진 열을 복사하거나 바꾸지 않는다.

이 파일의 편집자는 다른 군의 명단도 볼 수 있다. 담당자에게만 공유한다. 기존 등록·교육·메일 자동화와는 별도다.

검증은 프로젝트 루트에서 `node tests/event-day-workbook.test.js`로 실행한다. 로컬 검사는 Google의 실제 편집 이벤트와 권한을 대신 검증하지 않는다.
