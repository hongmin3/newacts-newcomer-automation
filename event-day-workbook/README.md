# 행축 당일 방문·등록 명단

2026년 11월 1일 행사 담당자가 전체 또는 군별 명단 한 곳에 적으면 관련 명단에 함께 표시된다. 과거 명단을 가져오지 않은 새 Google Sheets 파일에 연결된 별도 Apps Script다.

## 입력하기

1. `총 방문 새가족`, `총 등록 새가족` 또는 군별 탭을 연다.
2. 1행 머리글 아래 2행부터 이름과 휴대폰을 입력한다. 이름을 먼저 적고 연락처를 나중에 적어도 된다.
3. 군별 탭에서는 해당 군이 기본값이다. 전체 탭에서 군을 비우면 기타가 된다.
4. 등록 체크 시 전체 등록 명단에 함께 표시된다. 방문 이력은 유지된다.

입력 열은 B:R이다. 관리번호, 확인사항, 수정시각, 숨겨진 열과 원본 탭은 자동 관리한다. 여러 행을 붙여넣을 때는 B:R 안에서만 붙여넣는다. 전화번호가 없으면 이름만으로 같은 사람을 합치지 않는다.

## 정보가 다를 때

- 전화번호의 하이픈과 이름 앞뒤 공백은 정리한다.
- 같은 기록의 다른 항목 수정은 함께 반영한다. 같은 항목을 서로 다르게 수정하면 저장값을 유지하고 해당 행에 충돌을 표시한다.
- 충돌한 행을 선택한 뒤 `행축 명단` 메뉴에서 입력 적용 또는 저장값 복원을 선택한다.
- 군 변경, 이름 수정, 연락처 수정도 관리번호로 연결한다. 이름·전화번호가 완성될 때 다른 기록과 같아지면 중복 연결을 검사한다.
- 같은 번호의 다른 이름이나 연락처 없는 동명이인은 확인사항에 표시한다. 임의로 합치지 않는다.

메뉴 기능은 처음 실행할 때 Google에서 이 파일을 조회·관리하는 권한 승인을 요청할 수 있다. 일반 편집 동기화는 별도로 동작한다.

## 다시 맞추기와 취소

- 일반 입력은 편집 후 자동 반영된다. 빠른 연속 입력이나 통신 오류로 대기·중단이 표시되거나 명단이 맞지 않으면 `대기 입력 처리·전체 다시 맞추기`를 실행한다.
- 행을 직접 지워도 원본은 취소되지 않는다. 다시 맞추기로 화면을 복구한다.
- 취소는 메뉴의 `선택 기록 취소`를 사용한다. 원본과 이력은 남는다. `마지막 취소 복구`로 되돌린다.
- 취소 전 처리되지 않은 화면 입력은 변경 기록에 보관한다. 동일인 연결로 폐기한 옛 관리번호는 취소 복구 대상으로 삼지 않는다.

## 집계와 공유

행사 현황은 관리번호별 방문·등록 인원을 센다. 등록자는 방문에도 포함된다. 방문 인원과 등록 인원을 더해서 총 인원으로 쓰지 않는다.

군별 탭은 접근 권한을 분리하지 않는다. 파일 편집자는 다른 군과 숨김 원본도 볼 수 있다. 담당자에게만 공유한다. 기존 등록·교육·메일 자동화와는 별도로 동작한다.

## 유지관리와 검증

`Code.gs`는 이 새 파일에 연결된 프로젝트에서만 사용한다. 기존 `registration-project/`에 합치지 않는다. `layout.cjs`는 새 복사본을 비우고 구성하는 초기 설정 코드이므로 입력을 시작한 파일에 다시 실행하지 않는다.

```bash
node tests/event-day-workbook.test.js
```

자동 검사는 가짜 Sheets 경계를 사용한다. 실제 파일의 편집 이벤트, 권한, 모바일 동작은 별도로 확인한다. 행사 전 담당자 계정으로 가상 인물 입력·등록 체크·군 이동을 한 번 확인한다.
