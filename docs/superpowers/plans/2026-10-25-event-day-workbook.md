# 행축 당일 명단 최종 구현 계획

사용자가 확정한 기준은 빈 명단·11월 1일 하루·등록 입력 시 방문 자동 추가다. 추가 정정은 기존 파일의 양식 보존, 방문→등록 세로 배치, 비율·체크박스·결신·추가 버튼 제거다.

원본 두 파일의 군별 열 제목과 섹션 위치를 읽고 2025년 원본 군별 화면을 확인했다. 개인정보를 제외한 서식만 `event-day-workbook/reference-style.json`에 저장했다. 2026년 상반기의 9개 군과 기타를 쓴다.

1. 기존 연결 엔진의 관리번호·이름+전화 확인·항목별 입력 보존을 재사용한다. 화면은 원본의 열 구성으로 바꾼다.
2. `eventPlainMap_`과 입력 범위로 전체 및 군별 방문·등록 명단을 구분한다. 군별 시작은 방문 3행·등록 27행이며 아래쪽 등록은 행 삽입 시 함께 이동한다.
3. 원본의 파란 제목·빨간 열 제목·검은 테두리를 적용한다. 인원수 외의 지표와 추가 메뉴는 만들지 않는다.
4. 등록 입력→전체 등록·전체 방문·군별 방문, 등록 이름 비우기→방문 유지, 군 이동, 정보 충돌, 입력 범위 확장을 자동 검사한다. 가상 인물로 실제 파일을 확인한다.
5. 시험 명단·원본·이력을 비우고 인원수 0과 수식 오류 0을 확인한다. 자체 검사·준비 검사·워크스페이스 검사 후 문서와 코드를 함께 커밋·push한다.
