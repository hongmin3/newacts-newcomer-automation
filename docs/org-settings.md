# 군·팀 설정 운영 안내

비공개 설정 파일의 **군·팀 설정** 탭에서 군 순서와 팀 소속을 관리합니다. 미리보기에서 변경 내역을 확인한 뒤 적용하면 기존 출석 링크와 집중교육 폼, 1주차 층별안내도와 군별 보고에 같은 배치가 쓰입니다.

## 최초 연결

실제 파일 연결과 배포는 담당자가 확인한 운영 반영 시간에 진행합니다. 먼저 비공개 시험용 사본에서 설정과 아래 확인 항목을 시험합니다.

1. 군·팀 설정에 사용할 비공개 파일을 준비합니다. 출석 응답 파일이 링크 공개 상태면 별도의 파일을 사용합니다. 설정 파일은 신뢰하는 운영자에게만 공유합니다. 출석 응답 파일의 바인드 스크립트에 출석 프로젝트를 반영합니다.
2. 네 프로젝트의 실행 계정에 설정 파일 읽기 권한을 확인합니다. 출석 웹앱·교육·등록 프로젝트의 실행 계정에는 필요한 교육 파일 권한도 확인합니다. 운영 환경의 기존 폼·응답 시트·QR 파일, 출석 웹앱 배포를 식별합니다.
3. 아래 프로젝트별 스크립트 속성을 설정합니다. 시트 주소라면 `/d/` 다음의 파일 ID를 사용합니다. Google Form은 편집 주소의 Form ID를 사용합니다. 담당자가 출석 응답 파일을 다시 열고 **군·팀 관리 → 설정 탭 준비**를 눌러 설정 탭을 만듭니다. 공개 출석 웹앱을 갱신할 때 기존 배포를 선택합니다.
4. 층별안내도와 같은 비율의 한 페이지짜리 비공개 Google Slides 템플릿을 만듭니다. 기존 안내도 이미지를 배경으로 놓고 오른쪽 군·팀 표를 덮는 사각형 하나의 대체 텍스트 제목을 `ORG_TEAM_PANEL`로 설정합니다. 출석 프로젝트는 기본 폼 서비스와 매니페스트에 선언된 고급 Drive·Slides 서비스를 사용합니다. 표준 Cloud 프로젝트를 사용 중이면 해당 Cloud 프로젝트에서 Drive API와 Slides API 활성화를 확인합니다.
5. 설정 탭에 기존 군별 보고 담당자 메일을 채우고 승인된 편성표와 대조합니다. 표시 순서와 안내도의 영군 팀처럼 출석 화면과 원본 이미지가 다르게 표시한 부분도 함께 확인합니다. 첫 적용 미리보기에서 미수료 인원·수신자·안내도·폼 선택지를 확인합니다.

| 속성 | 설정할 프로젝트 | 값 |
|---|---|---|
| `ORG_SETTINGS_SPREADSHEET_ID` | 출석, 교육, 등록, 집중교육 신청 | 공통 설정 원본 파일 ID. 출석에서 메뉴로 탭을 준비하면 그 파일에 자동 연결됩니다. |
| `ORG_ATTENDANCE_RESPONSE_SPREADSHEET_ID` | 출석 | 현재 `설문지 응답 시트1` 탭이 있는 출석 응답 파일 ID. 같은 파일에서 설정 탭을 준비하면 자동 연결됩니다. 다른 파일로 옮길 때는 확인한 ID로 설정합니다. |
| `ORG_EDUCATION_SPREADSHEET_ID` | 출석 | 현재 `교육 출석 현황` 탭이 있는 파일 ID |
| `ORG_PREVIOUS_EDUCATION_SPREADSHEET_ID` | 출석, 교육 | 회기 간 미수료 출석을 이어갈 이전 교육 파일 ID. 해당할 때 설정합니다. |
| `ORG_ADMIN_EMAILS` | 출석 | 소유자 외의 승인된 관리자 계정. 쉼표나 공백으로 구분합니다. |
| `ORG_INTENSIVE_FORM_ID` | 출석 | 현재 운영 중인 집중교육 Form의 편집 주소에 있는 ID |
| `ORG_GUIDE_FILE_ID` | 출석 | 기존 QR이 사용하는 폴더에 있는 원본 PNG의 파일 ID |
| `ORG_GUIDE_TEMPLATE_ID` | 출석 | 위에서 준비한 비공개 Google Slides 파일 ID |

## 회기 전환과 팀 이동

1. 같은 회기 중 팀이 움직이면 현재 초안을 편집합니다. 새 회기에는 **다음 회기로 복사**를 누릅니다.
2. 군·팀을 추가하거나 팀의 소속 군을 고릅니다. 사라진 항목은 사용 체크를 끕니다. 같은 군의 이름·약칭을 바꿀 때는 그 행을 수정하면 이전 표기와 폼 문항이 연결됩니다.
3. 출석 응답 파일의 **군·팀 관리 → 미리보기 및 적용**에서 선택지, 안내도, 미수료 인원, 보고 대상과 팀 이동을 확인하고 **적용**을 누릅니다.
4. **적용 완료** 표시를 확인합니다. 중단된 경우 상태에 표시된 단계를 확인한 뒤 **중단한 적용 이어가기**를 사용합니다. 이전 배치가 필요하면 **이전 적용을 초안으로 복원**을 누르고 미리보기에서 확인한 뒤 적용합니다.

폼 편집 확인 전에 문제가 생기면 연결된 파일과 편집 권한을 확인합니다. 접수 중이던 폼은 적용 작업이 끝나면 다시 열립니다. 군·팀 설정 탭은 최신 회기 파일을 만들 때도 같은 운영 원본 하나를 사용합니다. 이전 회기의 교육 파일을 그대로 보관하고 변경된 참조가 있으면 설치 항목에서 확인합니다.

## 확인할 결과

- 기존 QR을 휴대폰에서 열면 같은 폴더·파일에서 새 안내도가 보입니다. PNG의 파일 ID와 공개 보기 설정을 확인합니다.
- 기존 집중교육 폼에서 추가한 군의 팀 분기로 이동할 수 있습니다. 응답 대상 파일과 열려 있던 접수 상태를 확인합니다.
- 2주차 날짜가 있는 미수료자는 새 배치에서 3주차 화면을 봅니다. 3주차 응답은 한 건이며 1·2주차 날짜와 당시 소속은 그대로입니다. 교육관리 시트에만 이력이 있거나 이전 회기 교육 파일에서 이어지는 사람도 같은 방식으로 확인합니다.
- 교육 반영과 군별 보고 미리보기에서 바뀐 군 이름·팀·수신자를 확인합니다. 테스트 발송은 기존 안전 모드를 적용합니다.
