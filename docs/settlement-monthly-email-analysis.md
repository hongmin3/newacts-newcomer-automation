# 정착률 월간 메일 자동화 분석

## 결론

첫째 주 금요일마다 정착률을 다시 계산하고 각 군 담당자에게 군별 보고 메일을 보내는 자동화는 가능합니다. 다만 정착률 계산은 Apps Script가 아니라 로컬 Python이 디모데 웹 화면에 로그인해 출결을 읽는 방식이므로, 현재 새가족교육 메일 트리거와 별도의 실행 기반이 필요합니다.

## 확인한 현재 구조

- 로컬 프로젝트: `C:\Users\2024980\Documents\자동화\정착률`
- 실행 파일: `main.py` → `settlement_automation.py`
- 입력: 등록 스프레드시트의 `등록 새가족` 탭
- 외부 조회: 디모데 교인 상세페이지의 연도별 `출결사항 > 주일`
- 출력: 같은 스프레드시트의 `정착률` 탭
- 산식: 등록일을 포함한 대상 일요일 중 주일 출석 체크 비율
- 안전장치: 동일인을 확정하지 못하면 정착률을 만들지 않고 조회 상태·사유만 기록

2026-08-14 확인 당시 `정착률` 탭에는 전체 421명, 조회 완료 403명, 전체 정착률 48.9%가 표시되어 있었습니다. 미조회 인원은 메일에서 별도 확인 대상으로 보여 주는 것이 안전합니다.

## 권장 실행 구조

```text
Windows 작업 스케줄러 (매주 금요일 오전)
  └─ 월의 1~7일인지 확인
       ├─ 아니면 정상 종료
       └─ 맞으면 정착률 Python 실행
            ├─ 디모데 로그인 및 출결 조회
            ├─ 정착률 탭 갱신
            ├─ 조회 성공률·오류 임계값 검사
            └─ 성공한 경우에만 메일 발송
                 ├─ 관리자: 전체·군별 비교 요약
                 └─ 군 담당자: 자기 군 상세 명단
```

Windows 작업 스케줄러는 “매월 첫째 금요일”을 직접 표현하기보다 매주 금요일 실행하고 프로그램에서 `오늘 날짜 <= 7`을 확인하는 방식이 단순하고 재현성이 좋습니다.

## 권장 메일 구성

### 전체 관리자 메일

- 제목: `[새가족부] 전체 새가족 정착률 현황 - YYYY-MM`
- 기준일과 최종 갱신 시각
- 전체 인원, 조회 완료, 미조회, 전체 정착률
- 9개 군의 명단 인원·조회 완료·대상 일요일·출석 일요일·정착률 비교표
- 미조회 또는 매칭 실패 인원과 사유

### 군별 담당자 메일

- 제목: `[새가족부] ○군 새가족 정착률 현황 - YYYY-MM`
- 해당 군 인원·조회 완료·군 정착률
- 이름·팀·등록일·대상 일요일·출석 일요일·정착률·최근 4주·조회 상태
- 낮은 정착률은 참고용 색상으로 표시하되 평가 등급처럼 표현하지 않음

수신자는 현재 교육 수료 메일의 운영 설정에 보존된 관리자 5명과 9개 군 담당자 매핑을 공통 설정으로 재사용할 수 있습니다.

## 운영 전에 보완할 점

1. 현재 `HEADLESS=False`이므로 무인 실행을 위해 headless 모드에서 디모데 로그인이 정상 작동하는지 별도 시험이 필요합니다.
2. PC가 켜져 있고 네트워크에 연결되어 있어야 합니다. 절전 상태에서도 실행하려면 작업 스케줄러의 절전 해제 옵션과 로그인 상태 정책을 정해야 합니다.
3. 디모데 화면 구조가 바뀌면 Playwright 선택자가 깨질 수 있으므로 실패 시 메일을 보내지 않고 관리자에게 오류 알림만 보내야 합니다.
4. 421명 전체 조회는 시간이 길 수 있으므로 중간 저장, 재시도, 마지막 성공 결과 보존이 필요합니다.
5. 현재 OAuth 토큰과 디모데 자격 증명은 로컬 비밀정보입니다. 저장소에 커밋하지 않고 Windows 자격 증명 관리자 또는 환경변수로 옮기는 것이 좋습니다.
6. 조회 완료율이 일정 기준보다 낮거나 이전 달보다 급락하면 보고 메일 발송을 차단해야 잘못된 통계가 운영 메일로 나가지 않습니다.

## 구현 권장 순서

1. 기존 Python에 `--send-email`과 `--first-friday-only` 옵션 추가
2. 메일 HTML 템플릿과 운영/테스트 수신자 안전 관문 추가
3. headless 단일 인원 테스트
4. 전체 계산 후 본인에게만 전체·군별 테스트 메일 발송
5. 결과 승인 후 Windows 작업 스케줄러 등록
6. 다음 첫째 주 금요일 실행 로그와 메일 도착 확인

이 자동화는 별도 승인 후 구현하는 것이 적절합니다. 현재 수료 자동화 운영 전환에는 포함하지 않습니다.
