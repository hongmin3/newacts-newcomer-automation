# 현재 연결 구조

## 데이터 흐름

```text
2026년 새가족교육 출석 (응답)
  └─ 설문지 응답 시트1
       │
       │ education-project/main
       ▼
뉴액츠 새가족부 교육관리
  ├─ 교육 출석 현황
  └─ 26년 집중교육
       │
       │ registration-project/runSystem
       ▼
2026년 뉴액츠 청년부 등록 새가족 현황
  ├─ 등록 새가족
  ├─ 등록 새가족 군 현황
  ├─ 상반기 방문 새가족
  ├─ 새가족교육 수료현황
  ├─ 상반기 결산
  └─ 정착률
```

집중교육 신청 접수는 기존 출석·등록 자동화와 분리된 독립 흐름입니다.

```text
집중교육 신청 Form
  └─ 관리자 Spreadsheet / 집중교육_신청자_관리
       │ onFormSubmitHandler
       ├─ 관리용_명단 (전화번호, 중복 의심, 처리상태 포함·비공개)
       └─ 공개 Spreadsheet / 신청확인명단 (전화번호 없음)
```

## 원본 프로젝트 역할

### 등록 프로젝트

- 등록 명단을 군별 현황판으로 재작성
- 등록 명단을 방문자 명단으로 동기화
- 교육 출석 현황과 등록 명단을 결합해 수료현황 재작성
- 군별·전체 통계 및 배정 필요 명단 메일 발송
- 결산 데이터 생성 함수 제공

### 교육 프로젝트

- Google Form 응답에서 직전 일요일 출석 데이터 반영
- 주차별 출석, 중복, 번호 불일치, 군·팀 변경 감지
- 교육 진행·미진행 문자 대상 명단 메일 발송
- 집중교육 참석자를 교육 출석 현황에 반영

### 집중교육 신청 프로젝트

- 군 선택에 따라 해당 군의 팀 Section으로 분기
- 숫자 전화번호를 `010-xxxx-xxxx`로 정규화하고 형식 검증
- 관리자 명단에 이름+전화번호 기준 중복 의심 표시
- 공개 확인 명단을 군→팀→참석자 이름 순으로 정렬
- 관리자 파일은 비공개로 유지하고 공개 확인 시트에만 링크 읽기 권한 부여

## 기준 데이터의 현재 방향

현재 코드는 교육 설문에서 입력된 군·팀을 교육 시트에 반영하고, 등록 프로젝트가 다시 교육 시트의 군·팀·전화번호를 등록 시트로 역동기화합니다. 즉, 교육 입력이 등록 정보까지 변경할 수 있는 구조입니다.
